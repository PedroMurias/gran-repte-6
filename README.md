# El Gran Repte de 6è

Concurs de preguntes de 6è de Primària (Medi, Català, Castellano, Mates i English) per al Centre d'Estudis Jaume Balmes.
Web: https://pedromurias.github.io/gran-repte-6/

- 4 modes: Concurs (Ràfega + Rosco), Cofres, Entrenament i Equips.
- Funciona com a app instal·lable (PWA) i sense connexió.
- Punts i classificació de la classe amb els comptes d'Explora Primària (Firebase `balmesonlinecom`; regles a `firestore_rules_gran_repte.txt`).
